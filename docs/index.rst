hydromt_hurrywave documentation
===============================

**hydromt_hurrywave** is a `HydroMT <https://deltares.github.io/hydromt/>`_ plugin
for the `HurryWave <https://github.com/Deltares/HurryWave>`_ spectral wave model.

It provides automated model building, including grid generation (regular and quadtree),
bathymetry interpolation, boundary condition setup, and forcing configuration.
